#1. Real Estate CRM

## Description
This is a React-based CRM project for real estate management. The app runs locally using the React development server and provides the foundation for the frontend of a real estate CRM.

## Tools & Versions
- Node.js: v24.9.0
- npm: v11.6.0
- React: v18.2.0
- VS Code (or any code editor)

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/Sethu2704/real-estate-crm.git

2.Navigate to the project folder:
cd real-estate-crm

3.Install dependencies:
npm install

4.Start the development server:
npm start

5.Open your browser and go to http://localhost:3000
 to see the default React welcome page.
